OKO Holding Corporation is a Delaware C-corporation headquartered in Jupiter, Florida, founded by Mo Perez, David Thrower, and Jonathan Castoire. OKO builds Thunderline, a governed operating substrate for human-agent teams where every consequential action produces a byte-verifiable receipt an auditor can replay. Thunderline's trust model is one cryptographic chain: a 4-tier policy gate (:read, :mutate, :admin, :execute) across 42 executor modules, a 17-field sealed ActionReceipt per authorised action, and a persisted lineage edge cross-checked on every traversal. Untrusted code runs in a hermetic WASM cell with zero imports, bounded fuel, and a wall-clock deadline — four distinct termination atoms, no silent fallbacks. OKO's first live application, ACORN, is a reference workflow built on the substrate. Prism is the operator surface. ThunderBlock is the beta managed workspace. IVAR is the design-partner-stage vision-analysis application for field operations. All maturity labels are published, not aspirational.

EDITORIAL POSTURE

What we are not claiming.

If you're writing about OKO or Thunderline, we'd rather you have this list up front than correct it in a retraction.

  • No SOC2 Type II audit. Roadmap target: Q1 2027.
  • No formal verification claim.
  • No customer logos or case studies — we do not have them yet.
  • No fabricated metrics (revenue, call counts, user counts, latency SLAs).
  • Receipt seals are tamper-evident, not tamper-proof (unkeyed; see /security).
  • Thunderline is not AGI. It governs agent actions, not agent reasoning.
  • Every product name carries a mandatory maturity label (research substrate / beta / live / design-partner stage). Dropping the label implies production readiness we have not claimed.

Full technical posture for engineering reviewers: /security.
